# Linux2WindowsDebianRepo
在Linux修復之際，我們需要一個deb倉庫

## 相關指令教學
control文件格式：
```txt
Package: 套件名
Version: 版本（若無則填入1.0-1）
Section: utils
Priority: optional
Architecture: amd64
Maintainer: 人 <信箱>
Description: 修复 Linux 没有 ______ 的 Bug
```
